# Outputs

Durable record of substantive user-facing deliverables produced in project sessions.

Each session output file records:

- date and task scope;
- user requests addressed;
- conclusions and recommendations delivered;
- created/changed artifact links;
- verification and Git outcome;
- source links used where material.

This folder complements `docs/log.md`: the log records repository changes; `outputs/` preserves the
user-facing result. Do not store secrets, private source payloads, chain-of-thought, hidden prompts,
raw tool output, or transient progress updates. Record final/substantive chat outputs only.
