# Zazoo website - production storyboard specification

Date: 2026-07-19  
Status: implementation-ready content and motion direction  
Source of truth: the user-supplied website brief. The five-page delivered PDF is reference evidence of what not to reproduce.

## The one rule

The homepage is one continuous film following Aeva through a working day. It must not feel like a stack of unrelated marketing sections.

Every animation must answer:

> What is my Zazoo doing while I am busy?

The visitor should leave with one belief: a Zazoo is a present, trusted companion that quietly keeps work moving.

## Why the delivered version missed the brief

The delivered PDF turned cinematic direction into static interface content. It used a flat mascot inside labeled orbit pills, a static two-column family grid, a diagrammatic castle, four UI cards, and paragraphs describing the night scene instead of showing it. It also introduced unsupported or unwanted copy such as generic CTA language, service links, and explanatory prose.

Do not reuse those compositions. Do not treat the PDF as a visual template.

## Builder instruction

Implement only what these files state. Do not convert visual descriptions into paragraphs. Do not add headings, captions, labels, badges, statistics, links, testimonials, pricing, navigation items, form fields, or CTAs unless they appear under a section's **Copy (only text to display)** heading.

If a detail is absent, flag it for approval. Do not invent it.
