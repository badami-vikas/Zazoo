Each prompt below is self-contained and can be used independently. The prompts request visuals only; overlay copy should be added separately.

Make the organized production system—not the engine—the hero. Match perspective, historical period, lighting, and realism across both halves. Keep important detail in the lower two-thirds and outer edges, with calm low-detail space across the upper portion of each half for text overlay. No captions, labels, signs, logos, readable writing, watermarks, or border line.
