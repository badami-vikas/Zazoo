# Role-model learning, DealPilot relations, and standard table menus — roadmap intake

## Outcome

The roadmap now contains three connected workstreams from the 2026-07-14 requirement.

1. **Personal learning:** Egg EG1 asks about admired public figures, then the Learning Agent performs governed, cited public research and recommends relevant Skills and scheduled Automations. Recommendations expose rationale, cadence, permissions, benefit, and stop condition; normal approval remains mandatory.
2. **Progressive reflection:** Egg EG3 asks about valued personal qualities after seven days and continues with configurable, context-relevant questions. Users can skip, snooze, pause, inspect, correct, and delete learnings. Behavioral learning cannot become diagnosis, covert profiling, protected-trait inference, or manipulation; each learning must connect to a visible value improvement.
3. **Module data/UI grammar:** DealPilot Deals, Sources, and Theses are sibling database-backed toggle pages with symmetric many-to-many relations and entity-owned fields. Thesis changes trigger governed source discovery; Source changes trigger governed Deal discovery; link changes trigger explained fit rescoring. The standard column/toggle menu is compiler-owned for every Module, including conditional Add page/Remove page and the requested Notion-class column actions.
