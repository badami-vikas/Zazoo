## Rules

- Active execution order lives only in [`docs/TASKS.md`](TASKS.md).
- `docs/wiki/` contains concise summaries, rules, and navigation.
- `docs/raw/` contains detailed plans, specifications, requirements, decisions, schemas, audits, and historical archives.
- `docs/BUGS.md`, `docs/requests.md`, and `docs/APPROVALS.md` preserve evidence, intent, and governance decisions; they do not create duplicate task rows.
- `docs/log.md` records landed changes. Dated `outputs/` files preserve substantive user-facing results.
- New input first attaches to an existing task by outcome, root cause, or prototype test. Create a new task only for an independently deliverable outcome.
