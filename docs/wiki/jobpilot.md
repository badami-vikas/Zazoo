# JobPilot

BRD: [../raw/brd-jobpilot-2026-07.md](../raw/brd-jobpilot-2026-07.md) · delivery: [../raw/jobpilot-module-plan-2026-07.md](../raw/jobpilot-module-plan-2026-07.md)

- One installable Module. Goal: high-fit, truthful applications with less repetitive work and full Human control.
- Left-nav click → Module Detail: Pages, Databases, Agents+their Skills, Automations, Integrations, Files, Runs, settings. Every visible item opens context or safe Action.
- Core: Candidate Profile, Job Postings, Applications, Sources, Materials, Answers, Interviews. Evidence-backed green/red decision is defining interaction.
- Authorized structured Sources first. Tailored claims resolve to verified Candidate Profile evidence. Submission requires explicit Human approval at launch.
- Skills exist only under allowed Agents. Automations create Agent Requests. Pacing Gate blocks spam; taint/provenance survive every boundary.
- Delivery JP0–JP6. Acceptance includes real data/empty states, standard UI grammar, desktop+375px proof, no display aliases.
