# Roadmap (wiki)

full: [../raw/ROADMAP.md](../raw/ROADMAP.md)

Sequenced by platform LAYER, not feature. Build enablement before surfaces.

- **P0 Substrate & Tenancy**: schema + RLS deny-default + auth + encryptable seam (relationship tier).
- **P1 Governance Spine**: permissions/policies/ledger/traces/policy_params + Universal Action Pipeline + Variance Adjuster. (Before ingestion — retrofitting pipeline = pain.)
- **P2 Registries & Runtime**: skills/agents/rituals/tools + thin agent runtime + ritual engine. Rituals/Tools = config rows.
- **P3 Ingestion & Knowledge**: Gmail/GCal idempotent + voice/quick-add + files + pgvector retrieval. canonical enrichment + identity resolution (Splink).
- **P4 Intelligence & Surfaces**: events→signals + Network Action cards (Signal→Context→Insight→Action) + pages (Network/Work/Intelligence/Settings) + Orbit visual + seed rituals/tools.
- **P5 Pilot & Learn**: 1–2 funds, watch Variance Adjuster learn from vetoes.
- **P6 Zero-Knowledge tier (DEFERRED, last)**: E2EE relationship tier, client-side search, scoped AI release. Pilots run RLS-isolated under contract until then.
