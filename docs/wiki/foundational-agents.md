# Foundational Agents + Onboarding

historical source: [../raw/bridge-foundational-agents-onboarding-2026-07.md](../raw/bridge-foundational-agents-onboarding-2026-07.md) · current vocabulary: [../glossary.md](../glossary.md)

**4 Agents + 1 Skill:** Chief of Staff (sole router/default interlocutor) · Learning (research/observation/corrections, never executes) · Governance (explains deterministic policy/control decisions) · Capability Builder (tested governed capability changes) · Communications Skill (draft/summarize/explain; no Agent authority).

**One Onboarding flow:** trust copy → essential preferences with immediate purpose → permissions with live proof → one performed value beat → approval-gated Module/Skill/Automation recommendations → one next action. Public-role-model research is cited and governed. Progressive reflection continues later with why/skip/snooze/pause/inspect/correct/delete.

**Avatar:** one visual companion/status surface. Visual style never sets Agent authority or communication tone. Operational presence may show idle/working/awaiting approval/blocked/error. Blink is capture Event tell, not personality/lifecycle state.

Legacy runtime names and persisted payloads remain real code debt. VOCAB1 migrates them with compatibility reads/backfill and deletion; UI copy alone cannot close task.
