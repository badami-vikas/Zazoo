# Clients + Context Providers

full: [../raw/client-architecture-context-providers.md](../raw/client-architecture-context-providers.md) · current shell canon: [ui-architecture](ui-architecture.md)

- One platform, three clients. Desktop = deepest local/OS capability. Browser = reach. Mobile = capture/awareness/Decisions. Same Organization, Modules, Memory, governance.
- Context Providers: apps/accessibility/screen/voice/clipboard/filesystem/browser/documents/email. Raw Capture Local Plane. Consumers receive privacy-filtered Context Observation. Avatar blink = capture tell.
- Every installed Module = clickable left-nav item from installation manifest. Module click → Pages/Databases, Agents+their Skills, Automations, Integrations, Files, Runs, settings.
- Relationship primary toggles = Signals/People/Communities. Signal = surfaced participant-linked Event.
- Second Brain below Modules = real permission-filtered cross-Module graph. No global data-index surface.
- Left Sidebar/right Chat Panel share expand/collapse/extend icons, width state, inner-edge resize, keyboard/ARIA, responsive overlay behavior.
- Desktop Avatar overlay = separate OS window; must drag, persist, follow Spaces/displays, and integrate window controls. Browser/mobile use in-page Avatar.
- Every interactive-looking item opens detail/edit/filter/explanation/governed Action. No dead cards.
- Current prototype violates several bullets; BUGS + PROGRESS interrupt 1A–1I own migration. No display aliases count as completion.
