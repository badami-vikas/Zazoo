# Freelancer implementation handoff (high-level)

Full doc: [../raw/freelancer-implementation-requirements-2026-07.md](../raw/freelancer-implementation-requirements-2026-07.md)

## What freelancer is building

- Production-ready Bridge runtime + Module system.
- Trust-first behavior stays intact.
- Web/desktop/mobile consistency improves without changing core architecture.

## Must not break

- Pipeline governance chain.
- Local Plane / Cloud Plane boundary.
- Signed capability/package trust path.
- Module/actionability canon (Agents own Skills, Automations start Agent Runs).
- No runtime dummy data.

## Delivery bar

- Small increments, evidence-backed validation.
- Security + reliability impact called out every change.
- Docs and ledger updated with each substantive delivery.
