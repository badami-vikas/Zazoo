## Terminology note

The founder memo uses **Egg** as the first-run experience metaphor: the small, complete Bridge environment a new user receives before Onboarding shapes it around their work. Egg is not a residency boundary, authority state, or separate data model; after setup, the user has Bridge, an Avatar, and installed Modules. Current architecture terms remain Avatar, Onboarding, Local Plane, Modules, and Commons. “HeyClicky-like” describes the desired immediacy and friendliness of the desktop companion, not permission to copy another product’s protected code, assets, wording, or distinctive design.
